# Zig 0.17.0 API and build system
Confirmed Zig 0.17.0 std library conventions, breaking changes, std.Io/io_uring/fiber limitations, shared-library/C-ABI pitfalls, and build.zig specifics hit while working on squeezefs-zig.

## Build modes
- `b.standardOptimizeOption(.{})` yields **Debug** unless `--release` or `-Doptimize` is passed; a build profile that only sets LTO/strip does NOT change the optimize mode. In Debug the std gpa is `SafeAllocator` (stack trace per alloc/free, no bucket reuse ≈ 5 KB retained per allocation), so a Debug product binary's RSS grows with the allocation count and no gauge accounts for it. squeezefs-zig's product binary and SDK libs default to ReleaseSafe since efdc88b (rung 9); tests stay Debug; `-Doptimize` still wins.

## Entry point and I/O
- `pub fn main(init: std.process.Init) !void`; `init` gives `io`, `arena`, `gpa`, `environ_map`, `minimal.args` (`init.minimal.args.toSlice(arena)`).
- stdout: `Io.File.Writer = .init(.stdout(), io, &buf)` then `flush()`.
- `std.Io` is the explicit-io interface replacing `std.fs.cwd()`-style calls; file ops take an `io` parameter. Tests use `std.testing.io` / `std.Io.Dir.cwd()`.
- Formatting goes through `std.Io.Writer` with `{f}`. For growable buffers use `std.Io.Writer.Allocating` (ArrayList has no `.writer()`).
- `std.Io.Uring`, `std.Io.Threaded`, `std.Io.Dir/File` exist; `Io.randomSecure` gives secure randomness (`std.crypto.random` is absent).

## Environment variables
- `std.posix.getenv` does not exist (error: "root source file struct 'posix' has no member named 'getenv'"). The env type is `std.process.Environ.Map`; in tests the idiom is `var env = try std.testing.environ.createMap(gpa); env.get(key)`.
- squeezefs's `knobs.zig` exposes `present(raw: ?[]const u8) ?[]const u8`, `parseStr`, `boolKnob`, `intKnob`, `optIntKnob` (comptime key, env map pointer).

## std.Io executor limitations (why squeezefs ships SqzIo)
- No language-level async/await; `std.Io.Evented` ships `fiber.zig` with hand-written context switching for aarch64/x86_64/riscv64.
- `std.Io.Threaded` spawns a thread per concurrent task and cancels by signal (SIG.IO) via a `Thread.current` threadlocal, so foreign threads are uncancelable. Its run queue is LIFO (source of intra-test scheduling races).
- `std.Io.Uring` fibers reserve 60 MiB virtual with NO guard page, use 8-entry rings, `COOP_TASKRUN|SINGLE_ISSUER` without `DEFER_TASKRUN`.
- `std.Io.fiber.contextSwitch` inline asm omits AArch64 x18 from its clobber list; under LTO the switch got inlined with a live value in x18, segfaulting. Workaround: make the switch wrappers `noinline`.
- No `@fence`; express fence points as SeqCst accesses or acq_rel RMW.

## Shared libraries, interposition and C ABI
- `addLibrary(.{.linkage=.dynamic})` emits a SONAME by default, but `std.Build.Step.Compile` has no `-z nodelete` field; the CLI `zig build-lib ... -z nodelete` does set DT_FLAGS_1 NODELETE — use an explicit Run step (fallback: runtime `dlopen(RTLD_NOLOAD|RTLD_NODELETE)` self-pin).
- `-femit-h` is accepted but emits no header file — hand-write C headers and pin them with a C program built via `addCSourceFile`/`linkLibrary`.
- Stack-trace frames end with the unit in parentheses: the SOURCE FILE under x86_64 Debug's self-hosted backend (`… in test.x (foo.zig)`), the BINARY NAME under aarch64's LLVM (`… in test.x (squeezefs-foo)`). A test matching trace text must stop at the `(` (c68c18e: the hangwatch self-test passed on kamrui, failed on the VM).
- C-variadic `export fn open(..., ...)` works with `@cVaStart`; on aarch64 VaList is disabled under LLVM, so use the fixed-register AAPCS64 form there.
- Zig cannot catch panics; an interposing library must be total by construction plus a panic handler that cleans up before aborting.
- Inside an interposing .so, `std.posix` would resolve to the library's own exported symbols — use raw `std.os.linux.*` wrappers.
- `fstatfs`, `FUSE_SUPER_MAGIC`, `dlvsym`, `RTLD_NEXT` and `CMSG_*` helpers are absent from std and must be declared locally.
- Use `bundle_compiler_rt = true` for a static .a consumed by C.

## Breaking changes / gotchas
- `@cImport` removed — use `b.addTranslateC` in build.zig (how zstd 1.5.7 is vendored).
- std has zstd decompress only and no lz4 (squeezefs ships its own LZ4 block codec).
- `**` array repeat removed — use `@splat`.
- `std.ArrayList(T)` is unmanaged: `.empty`, `append(gpa, x)`, `deinit(gpa)`.
- `std.time.timestamp` gone — use `posix.system.clock_gettime`.
- `linux.errno(ret)`, not `linux.E.init`.
- `std.Thread.setName` needs an Io handle (squeezefs uses prctl directly).
- `std.Thread.Mutex` no longer exists; use `std.Io.Mutex` (lock via `lockUncancelable`, Io handle stored at init, tests use `std.testing.io`).
- `std.heap.pageSize()` for runtime page size.
- FUTEX_WAKE count is a C int (`maxInt(u32)` wakes one waiter).
- `io_uring_enter` discards the wait's ETIME when the same call submits SQEs — submit first, then wait with `to_submit=0`.
- `std.posix.iovec.base` is `[*]u8` and cannot hold address 0, so a zero iovec is not expressible.
- Test runner fails any test that logs at error level.

## Std modules of interest
- `std.os.linux.IoUring`: init/init_params, get_sqe, submit, submit_and_wait, enter, copy_cqes, read/write/read_fixed/write_fixed, poll_add, timeout, cancel, register_files/_sparse, register_buffers, register_eventfd, get_probe, setup_buf_ring/BufferGroup, provide_buffers; `std.os.linux.io_uring_sqe`.
- `std.os.linux.IoUring` does NOT support SQE128 (64-byte stride); use squeezefs's own `src/io/uring128.zig` for SQE128/CQE32.
- `std.hash.XxHash3`, `XxHash64`, `XxHash32` in `std/hash/xxhash.zig`.
- Fuzzing: `std.testing.fuzz({}, fn, .{})` with `*std.testing.Smith` (`eos`, `value`, `bytes`, `valueRangeAtMost`).

## build.zig
- Modules via `b.addModule`/`b.createModule` with `.root_module` and `.imports`; `build.zig.zon` has `.fingerprint` and `.minimum_zig_version`.
- `b.args` doesn't exist — declare `-Dtest-filter` via `b.option` (repeatable, prefix filtering).
- `runAllowFail` takes `.ignore` (lowercase).
- No `getInstallPath` — use `addSystemCommand` with `addFileArg`/`addOutputFileArg` + `addInstallBinFile`.
- LTO: `exe.lto = .thin/.full` requires LLD, so only set for Linux targets.
- Call `b.graph.poisonCache()` when configure logic reads git state; otherwise gitCommit output is cached and identity goes stale.
- Split debug info: `objcopy --only-keep-debug` → `addOutputFileArg("squeezefs.debug")`, then `objcopy --strip-debug --add-gnu-debuglink`.
- `Step.Fmt` options `{paths, check}`; `b.addFail` for refusal steps.
- `zig build` caches test results; there is no `--seed` flag; `--global-cache-dir` is not a `zig build` flag (use `ZIG_GLOBAL_CACHE_DIR`).
- The build runner prints `failed command:` lines whenever a step writes to stderr, even with exit 0.
