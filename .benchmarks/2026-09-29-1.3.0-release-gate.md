## 3. The fuzz leg's build and the two-sha ruling

The nightly compiler refuses `JoinedWire::with_client`'s opaque future — its
re-dial path (`client_at`) awaits `sym_join::resolve_holder_endpoint`, whose
FUTURE TYPE contains the door's own through the read divert (`ClaimSet::load`
→ `getxattr` → `token_serve` → `foreign_read_plane` →
`bind_holder_endpoint_on_demand` → `joined_resolve_endpoint` →
`with_client`): a type-level cycle, never a runtime one (a re-dial reads
the claim set from the device — `claim_set` is not token-carried), which
the stable 1.98.1 solver accepts and every nightly tried (2026-09-26,
-09-10, -08-25) rejects with `E0275` — the RPIT's `+ Send` bound re-proven
against its own instantiation (the reviewer's standalone repro). The type dates from
PR 12b (2026-09-17) and no nightly had compiled it since: 1.2.4's fuzz leg
(2026-09-11) predates it, and attempts 10 / 12 / 13 stopped before leg 7.
The fix erases the ONE await on the cycle's return edge — the re-dial's
endpoint resolve, entered only after a transport failure — to `Pin<Box<dyn
Future + Send>>`; every other frame stays unboxed and the hot verb path is
untouched. Red-first is the nightly build (E0275 → `Finished`); stable-side,
`task check`'s lints and the joiner suite (`sym_n_daemon_tests` 108/108,
whose failover contracts drive this re-dial) are green on the fix. Rails
added: `task check:fuzz-nightly` (one nightly build of the workspace, run
before every chain and after any change to an `impl Future`-returning
door — not in `task check`, CI has no nightly) and the driver's preflight
running it before leg 1.

**The owner's ruling (2026-09-29)**: "we only worry about fixing the fuzz
leg and testing it again and whatever is after it … if something fails
from an actual code defect that might break things then we pause." The six
product legs' evidence stands on `b2cfb3e4`; the fuzz leg re-ran alone —
first on `585d7377`, where it RAN and found the two oracle defects of
§4.4cg (the product's documented laws, mis-stated by the fuzz targets'
own assertions — not the pause condition), then clean on `1ce23c8e`. The
product diff between `b2cfb3e4` and `1ce23c8e` is the one boxed await,
whose behaviour is the same future type-erased. The chain's from-zero law
(AGENTS.md's counted-run discipline) is deliberately relaxed here by that
