## 1. What Z2 built (the seam law)

**The seam boundary is exactly the io_uring / ioctl / netlink syscall
surface.** No zcrx-capable NIC exists on the dev box or CI, so the Z2
machinery is split hard:

* **Above the seam — local contract venue** (`SQUEEZEFS_ZCRX_LANE_AREA_SIM=1`,
  socket recv standing in for NIC DMA into REAL area chunks): the
  PMD-aligned NUMA-bindable `ZcrxArea` + derived sizing, the lock-free
  span-grant ledger (`area_core::SpanLedger` — refcounts + MPSC
  free-return stack = the refill feed), the streaming PDU parser over
  chunk sequences (headers-only copied + priced, PDO pad skipped by
  arithmetic, payload as refcounted spans), the fill table (unknown-CID/
  overrun/SUCCESS-non-LAST violations, exact-length completion, per-op
  error ≠ poison), the ONE completion gather (`zcrx_gather_bytes`), the
  admission law (≤ area/2 in flight, parked = `zcrx_area_admission_waits`,
  never a mid-stream stall), the poison lattice + quiescence drain, the
  R5 `zcrx_area` component + Red arm gate, and the steering
  record/apply/rollback/restore/reap state machine (mock `NicControl`).
* **Below the seam — field-owed** (`d9dd990`; compiles everywhere, arms
  only behind the full probe ladder): the raw per-queue io_uring
  (DEFER_TASKRUN | SINGLE_ISSUER | CQE32, SQ depth derived),
  `IORING_REGISTER_ZCRX_IFQ` + refill-ring region (uapi mirrors
  byte-verified against a compiled C probe of the 7.1 headers — the
  const layout asserts caught one real drift, ifq_reg 96 ≠ 64, before
  any syscall could), multishot RECV_ZC with per-CQE area-token
  provenance refusal, span returns as rqes on last-ref drop, capsule TX
  as SEND SQEs (design §3) with partial resubmit, eventfd doorbell,
  NUMA thread pin; `EthtoolNic` (SIOCETHTOOL RSS/ntuple/channels —
  layouts C-probe-verified) and the genetlink HDS probe (compares the
  `ETHTOOL_A_RINGS_TCP_DATA_SPLIT` ATTR == ENABLED — the corrected
  2026-08-02 probe, pinned in code); the arm ladder (RECV_ZC probe →
  route→ifname → HDS gate → channels → highest-indexed queue picks →
  connect/register → steering LAST → go). Kernel note: the field client
  runs the one-shot `6.19.14-sqz` and the fleet runs 7.1.2 — the probe
  ladder is identical on both (same zcrx uapi; every gate is a runtime
  probe, no version tables).

Z2 completion posture (design Rev 2): fills complete as refcounted
area-span scatter lists; the funnel destination is filled by ONE gather
pass (`zcrx_gather_bytes ≈ zcrx_fill_bytes`). Pass count vs today is
1:1 (the kernel RX copy is replaced by a userspace gather); **the
Phase-1 CPU deletion lands fully at Z3**, which fuses this pass into
`serve_copy_to_dest`. Chunk-backed `Bytes` never crosses the funnel —
downstream tiers retain served `Bytes` indefinitely and a pinned chunk
is admission starvation; the area is never a cache tier (§4.4).

`#[path]`-included; `LOOM_MAX_PREEMPTIONS=3`):

* `zcrx_chunk_recycle_never_races_consumers` — **PASS**: a re-granted
  chunk's recycle write can never race any consumer's payload read

## 5. The Z3 reformat-window acceptance script (prose — what the bracket must run)

Epoch lock honored this session: **no mounts, no deploys, no NIC
changes** — the steering code ships but first executes in the window.
On the field client (squeeze-test), after the reformat unblocks
post-bit-6 binaries:

1. **Arm proof**: mount the staged pair with `SQUEEZEFS_ZCRX_LANE=1` on
   an nvme-tcp data volume. Expect the `zcrx-lane armed … (backend:
   zcrx RECV_ZC — PR Z2)` log, `zcrx_lane_armed=1`, `zcrx_area_bytes` =
   queues × derived area, and the NIC state delta = exactly {RSS
   restricted off the lane queues, one reserved-range ntuple rule per
   lane connection} (`ethtool -x/-n` before/after snapshots — record
   them; unmount must restore byte-identically, the steering suite's
   law live).
2. **Engagement closure**: a cold sequential read row (elbencho, stated
   instrument); per-row stats-inode deltas must close byte-exact —
   `zcrx_fill_bytes` ≡ the row's cold-fill bytes, `zcrx_gather_bytes` ≡
   `zcrx_fill_bytes`, `zcrx_fill_fallbacks` ≈ 0, `zcrx_frame_violations`
   = 0, `zcrx_lane_poisoned` = 0; steering fidelity via per-queue
   `rx*_bytes` deltas ≡ lane bytes (the Phase-1 instrument — this is the
   design-§11.1 contamination gauge).
3. **A-B-B-A bracket** (standing comparison rule): cold-read rows vs
   `SQUEEZEFS_ZCRX_LANE=0`, both orders, medians of 3, sustained-state
   (≥ 60 s) rows included; RX-side CPU (mpstat) + DRAM B/B (uncore
   census) alongside throughput — Z2's expectation is parity-class
   throughput with the RX copy moved into `zcrx_gather_bytes` (the Z3
   fusion deletes it; the −65–68 % CPU projection is Z3's bar, not
   Z2's — do not adjudicate the lane on Z2 CPU).
4. **Loaded soak**: the lifecycle soak read legs (or the EXA validation
   read shape) ≥ 30 min with the lane armed: wedge tripwires 0
   (`zcrx_lane_poisoned`, `fuse_op_watchdog_overdue`, parked-gate
   timeouts), engagement still exact at the end, unmount restores NIC
   state and `zcrx_area_bytes` returns to 0.
5. **Failure lattice spot-check** (cheap, high-value): kill one lane
   TCP connection mid-row (ss -K / target-side reset) — expect ONE
   `zcrx_lane_poisoned` transition, zero failed application reads
   (kernel-path fallback serves), and a clean unmount + NIC restore.
