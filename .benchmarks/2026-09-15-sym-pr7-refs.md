## 1. What landed

Under bit 17 **and** `SQUEEZEFS_SYMMETRIC_META=1` (PR 4's plane) the data plane's two refcount DECISIONS — the W1 sole-owner patch and the terminal free — read the durable truth instead of the RAM count alone: one range probe in the referencing ino's slot tree (`block_ref_probe`) plus the SHARED mark of the clone protocol; a pack block's tenants are inos of ONE slot so its whole population sits in one slot tree (the `Packer` keys open packs by `(slot, data volume)`); a clone across two slot trees runs `MarkShared` → `ShareBlock` → publish-with-SHARED, and a terminal free of a SHARED block is decided at the index home; fsck C16 checks both sides of the index; a directory opts into gather-mode minting by xattr. **Unarmed (`=0`) and bit-17-absent mounts take the shipped path** (§2) — except for ONE PR-1 defect fixed on every forest volume (§1.1), which the first red pin found.

### 1.1 The PR-1 defect (`fix(meta)` `2c54f46d`) — a forest volume's references key their owner's LOCAL KEY ino

The forest codec routes a kind-6 record (`06 ‖ vol_tag ‖ block_idx ‖ owner_ino ‖ block_index`) by the top 24 bits of the OWNER at offset 17 — the local key form `(s + 1) << 40 | local` — while every product site keyed the owner's GLOBAL ino (the rung-19 law, `refs_owner`), whose top bits are zero for any realistic ino. Through the routed layer every reference of every slot's inode landed in the NATIVE slot tree (the manager's): complete as a census (the union over every tree), wrong for the plane — a publish from another appender would name the manager's slot (the cross-region refusal / the `Lease` class), and the pack law's per-slot probe read **0**. Pinned red on `6f8d44e6` by `a_layout_publish_through_the_routed_layer_lands_its_reference_in_the_owners_slot_tree`; fixed where `route_ino` lives:

- `RoutedMetaBackend::forest_ref_ops(v_idx, ops)` rewrites a symmetric-forest volume's reference owners to their local key form at EVERY routed entry point (`set_layout_and_size`, the group stage, `merge_layout_and_size` (+ chained), `commit_block_refs` (+ witnessed), `destroy_inodes_releasing` / `destroy_inode_chunked`, `migrate_block_map_train`, `kvmap_truncate_handoff`); a flat volume's ops pass through borrowed (`Cow`), byte-identical (`a_flat_volumes_ledger_keys_the_global_owner_verbatim`).
- The offline conversion (`config_ops::collect_flat_records`) re-keys kind-6 owners under the stamp's width + resolved native slot (`shared_refs::local_key_owner`), and the kind-6 set oracle (`builder::digest_backend_kind_set`) folds forest owners BACK to the global form (`rekey_owner` / `global_owner`) so the relayout digests equal (PR 11's contracts stay green on both legs).
- The two probe faces read either form: `block_ref_probe(vol, blk, Some(slot))` is ONE `refs_probe` over that slot tree (`SlotTrees::refs_probe`; `block_ref_probes`), `None` / a flat volume = the whole-volume `block_ref_count`. `a_backend_committed_reference_probes_in_the_slot_its_owner_names` pins the backend-level form.

### 1.2 Pack per `(slot, data volume)` (`pack.rs`, `routing.rs`)

`OpenPack` carries a `scope: u32`; the open map is keyed `PackKey { be_id, scope }`; `Packer::reserve(router, slot_len, scope)` / `refill` / `open_block` / `any_open(scope)` take the scope; `DataRouter::pack_scope_of(ino)` answers the ino's FOREST SLOT on an armed set (the mint policy's decision) and `0` otherwise, so `land_packed_image` / `repack_window` land a tenant in its slot's pack. Unarmed: ONE scope per data volume — PK2 byte-identical (`an_armed_set_packs_per_slot_and_an_unarmed_mount_keeps_pk2s_one_scope`: two slots → two open blocks → two `pack_blocks_sealed_dismount`; unarmed the same two inos share one block, one seal). `open_room_bytes` reads the roomiest scope; `open_scopes()` is the new gauge face (`pack_open_scopes`). The design's pin `a_pack_block_whose_slot_is_handed_over_keeps_its_whole_population_in_one_tree` runs the population before / after a slot handover (PR 4's `AcquireSlot` under the `1:4` partition) and across a crash-remount: the one-slot probe reads the whole population at every point, every other slot tree reads 0.

### 1.3 The shared-block index and the clone protocol (`kv/shared_refs.rs`, `routing.rs`, `block_allocator.rs`, `meta_ship/manager.rs`, `shared_ref_core.rs`)

- **The SHARED bit** is bit 1 of the block-ref VALUE's flags byte (`BLOCK_REF_FLAG_SHARED`, beside PK's `MAP_BLOB` bit 0; `BlockRefOp::taken_shared`, `BlockRefValue.shared`; a plain take's bytes unchanged — pinned).
- **The index** lives in **tree 0 of volume 0** as `shared_ref:` control records keyed by the GLOBAL owner (`shared_refs::index_home_volume()` is the ONE fn PR 8 re-points at the allocation holder; `TREE_SHARED_INDEX = 9` stays reserved and unwritten — §6 item 3). `share_block(refs)` is idempotent (`(inserted, already)`), one control entry in ring 0's USER class under `manager_gate` + `manager_verbs`; `shared_index_population` / `shared_index_scan` read it back; `the_index_lives_in_tree0_and_never_pollutes_a_slot_trees_probe` pins that an indexed block's per-slot probe still reads its slot tree's references alone.
- **`MarkShared`** (`mark_block_refs_shared`): under the OWNER's 4a guard, ONE tx rewriting the reference with the bit (`Marked | Already | Gone`); `Gone` aborts the clone ENOENT-class before anything is written (`mark_shared_is_idempotent_against_the_durable_witness_and_gone_aborts_the_clone`).
- **The clone path** (`DataRouter::clone_share_blocks`, called from `clone_file` after the pins and before the dest publish): on an armed set whose src and dest live in DIFFERENT slots, step 1 marks every source reference (RAM mark set beside it — `BlockAllocator::mark_shared`), step 2 indexes both inos' references (`share_block`, chunks of 512), step 3 the dest publishes its references WITH the bit in the same tx as its layout — the ORDERING law: a reference is published only after its mark is durable at the owner. A failure undoes the pins and the spill site. A clone of a clone inherits the bit (`a_clone_of_a_clone_inherits_the_shared_bit`).
- **The W1 predicate** reads the mark under the same 4a guard `MarkShared` applies under: `begin_patch_sole_owner` = `refcount == Some(1) && !is_shared(offset)`, counted on `patch_ineligible_shared` (the ledger's existing clause) — **and confirms the RAM verdict durably on an armed set** (`DataRouter::sole_owner_durably(ino, allocator, offset)`, ONE call at the patch site in `fuse_client.rs` after `begin_patch_sole_owner`): one `block_ref_probe` of the patching ino's slot tree, `Ok(1)` = patch, anything else (a reference a PREDECESSOR lessee committed into a tree handed over since — which this mount's RAM map, seeded at ITS open, never saw — or an unreadable probe) = the CoW fallback. Unarmed / flat: `true` without a read. `the_w1_predicate_confirms_sole_ownership_in_the_inos_slot_tree_on_an_armed_set` pins both (a backend-committed ghost reference in f's slot refuses the patch while RAM still reads 1). This is the probe's PRODUCTION caller in PR 7; the free list's is PR 8's (§5 item 1).
- **The terminal free of a SHARED block is never decided locally**: `BackendRouter::free_block_verdict` finds the RAM mark and, with the free gate installed (`DataRouter::arm_shared_refs` at mount — `src/main.rs` after `set_meta_backend`), asks the home's `release_shared` (`SharedRelease::{NotShared, Held { remaining }, Freed}`): `Held` decrements the RAM count only while it stays > 1 (`release_shared_held`) and counts `pack_partial_frees` for a tenant-shaped key; `Freed | NotShared` clears the mark and runs the ordinary `begin_free`. The GC arm (`release_shared_at`) probes the flags of every indexed owner through `route_ino`, so a cloner that died after `ShareBlock` leaves entries C16 reports and the release GCs (`a_cloner_dying_after_share_block_is_reported_by_c16_and_gcd_at_the_release`); one that died after `MarkShared` leaves a harmless flag (`a_cloner_dying_after_mark_shared_leaves_a_harmless_flag_c16_reports`).
- **The marks are seeded from the index at the arm** (`the_shared_marks_are_seeded_from_the_index_at_the_arm`) — the only per-volume read the arm performs (a `shared_index_scan` of the home, ∝ shared blocks, not references).
- **The verbs** ride `ManagerCall` as the PR-7 block at the END of the enum — `MarkShared { vol_tag, block_idx, owner_ino, block_index }`, `ShareBlock { vol_tag, block_idx, refs }`, `ReleaseShared { vol_tag, block_idx, owner_ino }` → `Marked { already } | SharedGone | Shared { inserted, already } | SharedReleased { shared, remaining }` (bincode carries the variant index; the brief's 0x70–0x7F range names this block; `MANAGER_SCHEMA` 1, `CLUSTER_WIRE_SCHEMA` 5 unchanged). `ManagerClient::{mark_shared, share_block, release_shared}`; `the_clone_verbs_ride_the_manager_wire` runs them through `RpcListener` + `AsyncVerbRouter::with_manager`. The wire `ReleaseShared` takes NO GC verdict (§6 item 4).
- **The R6 pin** `a_clone_racing_a_truncate_never_frees_or_patches_a_shared_block`: a truncate's terminal free racing a clone's mark on the same block never frees it while the clone's reference stands and never patches it; both probes and C8 agree after.
- **Loom** `shared_ref_core` (`src/shared_ref_core.rs`, `#[path]`-shared into `loom-models/`): the mark word (`mark` = Release store, `is_shared` = Acquire load) composed as a THIRD word beside the W1 `patch_clone_core` / `refcount_core` fence pair — patcher `retire → fence(SeqCst) → peek == 1 ∧ ¬shared → publish`, owner `release → fence → is_shared`, cloner `mark → fence → try_acquire → fence → snapshot`. Invariants: the two-word law; never a patch past a visible mark; `¬(freed_locally ∧ pinned)`, `¬(shipped ∧ pinned)`; conservation. **Weakening result**: the patcher's `fence(SeqCst)` is load-bearing (→ `Release` fails); the cloner's two fences fail only when BOTH are weakened (stated in the test's doc).

### 1.4 C16 (`fsck.rs`)

`SuspectKind::C16SharedIndexDrift` / `FindingId::C16SharedIndexDrift { vol_tag, block_idx, owner_ino, block_index, flag_side }` — a SHARED flag without an index entry (`FlagWithoutEntry`) or an index entry whose ino carries no SHARED reference (`EntryWithoutFlag`); `shared_refs::shared_index_drift(routed, vol_tag)` is the census (every volume's flagged references resolved to their global owner vs the home's index — both sides), run as its own pass beside C8 in the unsharded run and the fleet finalize (§6 item 5), confirmed on a fresh census, report-only (the apply arm refuses), counter `shared_index_drift` → `fsck_shared_index_drift`. Every planted drift found, a healthy tree never (the two crash-window contracts + `a_clone_on_an_armed_forest_marks_the_source_shared_and_indexes_both_inos`).

### 1.5 Gather mode (`lib.rs`, `kv/backend.rs`, `meta_backend/mod.rs`, `kv/slot_lease.rs`)

`crate::GATHER_XATTR = "user.squeezefs.gather"` (the kernel's `user.` namespace — a `squeezefs.`-prefixed name never reaches FUSE), admitted by NAME through the reserved-xattr screen (`xattr_name_allowed`, the first clause — `user.squeezefs.gatherX` and the format config stay refused); `gather_xattr_opts_in` reads `1/true/yes/on` (trimmed, case-insensitive). `RoutedMetaBackend::gather_mint_slot(volume, parent)` is the ONE new arm, called first inside `pick_mint_slot_for`'s armed branch: a parent carrying the opt-in mints its child from the parent's slot cursor (`dir_gather_mints`) whatever the cap — excluded when the parent's slot is the native slot or another volume's (the ordinary policy decides). Never automatic: a plain directory past the cap spills to the rotor (`a_gather_mode_directorys_children_live_in_its_slot_past_the_cap_and_never_automatically` — also the closure `affinity_mints + rotor_mints + dir_gather_mints ≡ mints` and the opt-out by `removexattr`); unarmed the xattr is ignored and the gauge stays 0 (`an_unarmed_mount_ignores_the_gather_xattr_and_the_gauge_stays_zero`). The S10 `InoSupply` is not consulted: on an armed set the slot's cursor IS the mint's (PR 4 retired the bit-12 lanes for metadata under bit 17), so the holder's cursor is what the arm reads — §6 item 6.

### 1.6 The stats family (appended at the END of PR 4's symmetric block in `fuse_client.rs`)

`dir_gather_mints` (the lease snapshot), `block_ref_probes`, `share_block_calls`, `release_shared_calls`, `mark_shared_calls`, `shared_blocks` (an array of `{volume, shared_blocks}` over `durable_ref_volumes()` — the RAM mark population), `pack_open_scopes`; `fsck_shared_index_drift` beside `fsck_tenant_overlap_findings`; `pack_blocks_sealed_dismount` (PK2's, now the per-slot seal residue). All 0 on an unarmed mount (`an_unarmed_mount_clones_plain_and_every_gauge_stays_zero`).

## 2. The negative contract — `SQUEEZEFS_SYMMETRIC_META=0` and a bit-17-absent volume

Flat volumes: `forest_ref_ops` borrows (`Cow::Borrowed`) — the ledger keys the GLOBAL owner verbatim (pinned). The ONE change every forest volume sees regardless of the plane is §1.1's fix (a bit-17-absent volume is untouched).
