## What the rung landed (the ARM — S8 was built dark; nothing consumed it)

S8's machinery (`src/meta_ship/`) was built and suite-proven but **never
armed**: the authority's `AsyncVerbRouter` served only the custody +
publish blocks (`VERB_META_BATCH` answered UNKNOWN_VERB), and the
co-writer daemon's `Metadata`-trait verbs (unlink/rename/setattr/xattrs/
lookup/…) executed against the local backend, where the co-writer write
gate refuses them — AGENTS.md's own words: *"S8's un-routed-daemon gap
meeting a real workload"*. The S8-b falsifier is "any un-routed local
commit", so the arm has two halves:

1. **Owner half** — `AsyncVerbRouter::with_meta` claims
   `VERB_META_BATCH..=VERB_RECLAIM` for `MetaShipService` on the SAME
   listener `arm_multi_writer` starts (beside custody + publish; the
   service adopts the durable era at construction, so a successor's
   higher term makes old-era frames stale by construction).
2. **Client half** — `cowriter::arm` installs the process-global **daemon
   verb router** (`meta_ship::install_daemon_verb_router`), and
   `RoutedMetaBackend`'s `Metadata` impl consults it **at verb entry**
   (`meta_ship::daemon_verb_router` — one relaxed load on every unarmed
   mount, the solo re-gate's law), delegating to `MetaShipRouter` when
   the participant's volume has a FOREIGN owner. The hook lives in the
   trait impl so **no call site can bypass it** (the
   `pending_block_refs` correct-by-construction precedent); reads ship
   too (owner-current read-your-own-shipped-writes — S8 raw's honest RTT
   cost); the `".."` lookup stays local on BOTH layers (recursion-free by
   construction, pinned).
3. `PublishClient::ship` records the same `meta_ship_phase_ns.rtt` phase,
   so the published attribution covers the WHOLE shipped stream (trait +
   publish vocabularies), not just the trait half.
4. Rig: `mw_fleet.sh --cowriters=K` (the mechanized ops.md bring-up:
   rung-3 refusal id harvest → authority re-arm with
   `SQUEEZEFS_MW_MEMBERS` → co-writer mounts), µs-grain netem, and the
   matrix legs `s8-serial-ab` / `s8-crucible`.

Cargo pins (`tests/mw_arm_s8_tests.rs`, red-first at `ce7cdac6`): the
authority listener serves the S8 block end-to-end; a co-writer backend's
trait verbs SHIP with `local_commit_refusals` flat and shipped == served;
the solo re-gate (unarmed mounts never touch the plane, stale installs
inert); the `".."` bounce guard.

## S8-a — the R1 honesty row, PUBLISHED (spec: "published even if it regresses" — it does, exactly as R1 prices)

Fleet `N=2 --multi-writer --cowriters=1` (authority + 1 reader + 1
co-located co-writer in its own netns), 24 GiB/oss volume. Instrument:
**real linux-src subtree** (`linux/fs`, tarball of **2,384 entries**,
49 MB — mixed inline/striped file sizes, serial create-heavy with
per-entry utimes), extracted by real `tar -xf` over the FUSE mounts; one
tarball for every venue. RTT points: the netns veth (no netem ≈ the
loopback-class floor), then netem 125 µs / 500 µs per veth end (wire RTT
+250 µs / +1 ms — the design's S10-gate point and the 1 ms ladder top).
Row validity: shipped == served on BOTH ledgers (S8 trait + S9 publish,
±4 instrument self-skew), `meta_ship_publish.refusals == 0`,
`owner_panics == 0`, `local_commit_refusals == 0`. All held on every
venue.

**Attribution (the row names where the serial latency goes)** — phase

* client `meta_ship_phase_ns`: route ≤1 µs, queue_wait ≤8 µs, encode
  ≤1 µs, **rtt ≤2 ms (n=41,566 — trait + publish rides)**, decode ≤1 µs.
* owner `meta_ship_owner_phase_ns`: admit ≤1 µs, dispatch ≤32 µs, execute
  ≤8 µs, reply_encode ≤1 µs, total ≤32 µs.
* pipelining: `batched_verbs / batches` = **1.00** on every shipped venue
  — the serial stream never coalesces, exactly the R1 cost ruling D10
  accepted and §8.2's design text predicts ("a serial stream pays one RTT

**Reading.** The regression is 100 % wire: ~17.4 shipped verbs per tar
entry (lookups + create + writes' publishes + setattr — S8 raw ships

**R1 baseline S10's subtree delegation must recover** (§8.3's gate:

§6.10 R1 priced a serial op stream at 50–150 µs RTT dropping to
6.7–20 k ops/s before owner queueing: the measured **9,473 wire
verbs/s at the ~40–80 µs veth floor** sits inside R1's own band.
Published as demanded: it regresses, the mechanism works, every verb
accounts.
