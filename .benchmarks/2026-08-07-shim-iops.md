## 1. Phase 1 — the per-op cost ledger (the deliverable that gates everything)

### 1.0 The instrument the path was missing (landed)

The rand-4k il hot path is the direct-drive engine — **no handler, so `read_serve_phase_ns` structurally never sees it**, and the daemon-vs-client residence split was unmeasurable on production mounts. Landed: **`ipc_direct_phase_ns`** (always-on, shared `latency_core` buckets, the `write_pipeline_phase_ns` cost contract):

- `admit` = prelude probe entry → in-flight slab insert (eligibility + 795 snapshot + lane route)
- `inflight` = slab insert → CQE popped (SQE push + flush-batch wait + device/fabric service + reap batching)
- `finish` = CQE popped → slot completion posted (revalidate + accounting + bounce copy)
- `total` = probe entry → completion — the DAEMON residence; **`fio clat − total` = client + ring-ingress residence** (the ledger's subtraction)

Contract: `tests/ipc_direct_drive_tests.rs::direct_drive_serves_record_residence_phases` (red `1f3eaf31`, green `57eb2136`).

### 2.3 Lever C — reaper/drain fusion (landed, default ON, `SQUEEZEFS_IPC_DD_INLINE_REAP=0` = A/B lever)

Bracket at 32×8 (A-B-B-A): ON 740.9/740.7 vs OFF 742.3/745.2 k — **wash, engagement 10.7 % of serves**; 32×32: 1.044 vs 1.041 M, engagement 4.4 %. **Local reapers run ~20 % CPU — there is nothing to relieve here.** The field's reapers ran 80–85 % CPU beside 93 %-CPU submitters at saturation (`…-il-530k-ceiling.md`), which is fusion's target venue — the "local hides it" class (the balance-fix precedent: that mechanism was also structurally inert locally and +23 % in the field). ## 5. Standing residuals (filed, not built)

- **The client reap redesign** is the shaped follow-on the 1×8 row prices at 4.6×: neither blind 50 µs sleep nor per-completion event-park is right — a doorbell park with a *batch-threshold* wake (wake at `seq ≥ snapshot + K` or timeout, K from the caller's `min_nr`) would delete the observation quantum without the herd. Needs a `CqeDoorbell` protocol extension (loom-modeled, Dekker-fence-paired per the §2.2 lesson in the op-economy note).
- **Ingress stamp**: `IpcSlot` has a `_reserved: AtomicU32`; a client publish-instant would turn the ~160 µs client+ingress subtraction into two measured terms (needs a coarse `IPC_ABI` bump; clock domain is CLOCK_MONOTONIC both sides, same host).
- **The svc park ceremony at `SPIN_US=0`**: 26 % sys CPU on every svc thread (2× drain passes + flag stores + `futex_waitv` per empty cycle, 61 k parks/s at the ceiling shape) — a park-ceremony economy pass (cheaper rescan, coalesced flag stores) is unpriced.
