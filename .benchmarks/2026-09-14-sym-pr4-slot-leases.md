## 1. What landed

Under bit 17 **and** `SQUEEZEFS_SYMMETRIC_META=1`, the writer that wins the D0 ladder — PR 3's manager — LEASES its native slot plus `M` rotor slots through its own `AcquireSlots`, every lease a tree-0 record (`Leased { appender_id, g, page_addr, root, cursor, slot_tree_extents }` — the `slot_state` record's v2 image, `Unleased` gaining `last_written`) AND a `Live` entry `(slot, g, slot_tree_extents, root, cursor)` on the lessee's appender page — two durable homes at every instant, PR 2's `g = 0` / `slot_tree_extents = 0` made real. The node cache reads a THIRD gate state under the node's write lock (`meta_kv_leaf_lease_refusals`); new inodes mint by the bounded parent-slot affinity; a slot moves between appenders by flush-then-transfer at the holder's decision (dominance over one common window); the S4 lock plane homes on the live lease map (`dlm_mode` = `slot-homed`); the renewal `Grant` carries the member's leases, recalls and offers; the manager verbs ride the owner listener dispatched by volume. **`=0` is the shipped posture exactly** (§2).

### 1.1 The core (`src/slot_lease_core.rs`, `#[path]`-shared into `loom-models/`)

- **`LeaseGate`** — dense atomic bitsets (`SLOT_NAMESPACE` = the native slot + the u16 guest space) of the slots this mount leases and the slots mid-handover, plus the armed flag; `verdict(slot)` → `Unarmed | Allowed | NotLeased | Releasing`, read by `CachedNode::apply_locked` UNDER the node's write lock for a slot-stamped node. **The load-bearing order** (weakening-verified, `a_commit_never_lands_on_a_releasing_slot`): the departing holder raises `Releasing` BEFORE its flush takes any node lock, and the committer reads the verdict INSIDE the lock — a check-then-lock committer lands a record after the flush's snapshot (an acked record no ring holds and no page names), which is exactly what the weakened model reports.
- **`SlotLeaseTable`** — `Unleased → Leased → Offered → Releasing → Unleased` under one short-hold mutex; one holder per slot; `g` incremented at every grant, never at a replay, never at a release; every transition idempotent against the state it finds (KD-SYM-7). `acquire` answers `Granted { g, words } | Already { g } | Refused { holder, g } | Recall { holder, g }` (the accept of an offer); `release` answers `Already` only for an `Unleased` at the SAME `g` with the SAME words (the first build answered `Already` for any `g ≥`, which the loom model `a_stale_release_is_refused_and_the_live_one_lands_once` caught); `offer` / `expire_offers` / `begin_release` / `abort_release` / `resolve` / `held_by` / `pick_unleased`. Loom: `racing_acquires_yield_one_holder_and_one_g_increment`, `an_offer_expiring_under_an_accept_never_yields_two_holders`.
- **`DominanceWindow`** — per slot, the holder's own ops (`HolderOps`, lock-free two-epoch buckets) and each requester's ships over the same `T_idle` window in a bounded table (`REQUESTERS_PER_SLOT_MAX` = 8 — the offer names ONE identity, so with 8 equal requesters none reaches the holder's 2×; LRU-evicted, never a per-node allocation per ship); `note_ship` → `Serve | OfferIdle { to } | OfferDominated { to }` iff `ops_q ≥ 2 × ops_h ∧ ops_q ≥ N_floor` for one requester.
- **Derivations** (tie-tested): `mint_slots_derived(W, writers) = clamp(W / (2 × writers), 1, 64)`; `affinity_ceiling_bytes(used, node) = max(used / 64, node)`; `n_floor(handover, ship) = max(2, ceil(handover / ship))`; `handover_cold_start_ns = 4 × barrier + 3 × ship RTT`; `mint_choice(parent, rotors, a_max, node_size, rr, may_overflow)` with SIGNED headroom (i128) so over-cap trees equalize under the rotor arm.

### 1.2 The plane (`src/meta_backend/kv/slot_lease.rs`, `backend.rs`)

- **The arm** (`arm_slot_leases`, the join's last step): load tree 0's `slot_state` population → settle every loaded page's slot entries against it (§1.5) → re-adopt the slots tree 0 already names as ours (a crash-remount; region 0's re-adopted non-native slots fill its rotor up to `M`, since tree 0 does not tell a rotor slot from a handover-acquired one) → `AcquireSlots` for the native slot (KD-SYM-2) → the PR-2 seam's declared slots for every declared region, reconciled against tree 0 as a WISH-LIST (unleased or already the region's; another appender's holding is left to it) → the rotor to `M` (`prefer: unleased-then-idle` over the hosted routing slots) → `publish_slot_owners` (`install_local_slots(Some(local))`: every routing slot local but the ones a FOREIGN appender leases — `dlm_mode` = `slot-homed`, `dlm_rpcs` 0 by construction on a solo mount) → the holder cache refreshed → `gate.arm()` → the plane registered with the membership carriage.
- **The verbs** (`manager_acquire_slots` / `manager_acquire_slot` / `manager_offer_slot` / `manager_release_slot` / `manager_resolve_slot` + their wire faces; `ManagerCall::{AcquireSlots, AcquireSlot, OfferSlot, ReleaseSlot, ResolveSlot}`, `MANAGER_SCHEMA` 1 under `CLUSTER_WIRE_SCHEMA` 5 — the program's unreleased wire; the request frame gained its VOLUME ordinal): every grant is ONE tree-0 put per slot, every put of a call ONE control entry in ring 0's USER class; a rotor ask past `2 × M` (non-native leases) refuses `Busy` naming the knob; an explicit ask for a slot another appender holds refuses naming the holder ("ship to the holder") and rolls back the call's unwritten grants; `Already` for a slot the caller holds (KD-SYM-7, `manager_verb_replays`); a fresh grant to a WIRE joiner writes its page's slot entries. `ReleaseSlot` checks the durable witness FIRST (tree 0 `Unleased` at that `g` with those words = the replay; another holder / another `g` = `manager_verb_refusals`).
- **Minting** (`RoutedMetaBackend::pick_mint_slot_for(volume, parent)` → `lease_mint_choice` / `lease_mint_overflow`): the parent's slot while leased and under `A_max(t)` (`affinity_mints`); else the rotor slot with the most headroom (`rotor_mints`, `affinity_ceiling_spills` when the parent's tree was over the cap); every rotor tree STRICTLY over the cap by ≥ 1 extent asks one more rotor slot up to `2 × M` (`affinity_ceiling_overflows`); past `2 × M` the smallest rotor tree. `A_max(t)` is recomputed at the mint from the volume's live leaf-byte census (`affinity_a_max_bytes`), or `SQUEEZEFS_SYM_AFFINITY_MAX_MB` clamped to `[node_size, heap]`. A commit whose records name an UNLEASED slot acquires it for region 0 first-writer-takes-it (`ensure_leases_for_tx`); one naming a FOREIGN holder's slot refuses at the door.
- **Handover = flush-then-transfer** (`release_slot_handover`, serialized per volume by `KvMetaBackend::handover`): gate `Releasing` → `table.begin_release` → `checkpoint_now` (every dirty leaf, barriered) → the moved root published (`note_page_published`) → a SECOND `checkpoint_now` (the region's tail passes the slot's records — §6 item 2) → the page with the slot `Releasing { root, cursor, g, extents }` + barrier → [`TEST_HANDOVER_HOLD_AFTER_PAGE`] → `manager_release_slot` (tree 0 `Unleased { root, cursor, g, slot_tree_extents, last_written, tails }` + the departing grant record rewritten without the tree's live images, one control entry) → [`TEST_HANDOVER_HOLD_AFTER_TREE0`] → RAM drop (region lease, gate, dominance, extents, rotor, the guest cursor) → the page without the slot. `slot_handover_phase_ns` records `flush / page / tree0 / grant / total` exact-sum (`grant` = the requester's `grant_one_slot` on the accept path). The requester's `AcquireSlot` of an offer TO IT recalls an in-process holder here and grants at `g + 1` with the tree's live root; a WIRE holder's offer becomes a RECALL notice on its next renewal grant (§1.6) and the requester is answered `Refused { holder }` to retry.
- **Dominance** (`note_slot_ship(slot, requester)` at the served ship; `note_slot_ops` at the commit door counts the holder's own): the `DominanceWindow` verdict, the cooldown (`recall_cooldown_from` over `T_idle` — 8 windows — after a handover: no new offer of that slot), `manager_offer_slot` with an expiry of `min(10 s, T_idle / 3)`; `slot_offers{,_idle,_dominated,_expired}`, `slot_ships`, `slot_offer_n_floor` (the EWMAs of the handover's and a ship's wall feed `N_floor`; cold start = `handover_cold_start_ns`).
- **The cadence** (`slot_lease_cadence`, after every checkpoint tick and directly by the contracts): expire offers; forced shrink — `M` re-derived from the census in force (`appenders_known`, or the seam `test_writers_known`), idle rotor slots beyond it released least-extents-first (`slot_forced_shrinks`), re-read per release so a concurrent pass never over-releases; LRU release of idle non-rotor slots past `SLOT_PAGE_BUDGET` = 108 (`slot_lru_releases`); a declared region with no lease and a drained ring released — the grant's remainder returned, the page `Free` into both directory slots, the ring's extents freed and their bits written, once (`slot_region_releases`). A concurrent release of a slot another pass already took is the `Busy` class, skipped.
- **The leave** (`release_leases_at_leave`): every covered region's leases go `Unleased` with their final words and tails, one control entry per region; the rotor empties; `install_local_slots(None)` (`dlm_mode` back to `solo`); the carriage source unregistered. A crash leaves the leases with the `Live` pages for the next open's re-adoption.
- **A LEASED slot's root rides its lessee's PAGE, never tree 0** (KD-SYM-3): `publish_forest_roots` skips leased and releasing slots; `write_appender_pages` records the page's publication of every `Live` entry's root (`SlotTrees::note_page_published` — counted only when the root moved); an UNLEASED slot's re-publication (an SMO of a tree nobody leases) keeps its release record's `g` / cursor / `last_written` and recomputes the tails, and the RAM table's words follow (§6 item 1).

### 1.3 The gate, the ledger, the records

- `NodeCache.lease: Arc<LeaseGate>` (built at open; `CachedNode::from_loaded` carries it); in `apply_locked`, after the interior gate, a slot-stamped node's mutation is refused `NotLeased` / `Releasing` — `META_KV_LEAF_LEASE_REFUSALS`, the belt behind the commit door.
- `SlotExtentLedger` (scc, slot → images) maintained at every slot tree's claim / free / release through `SmoContext` (`note_claim` / `note_free`, the forest's mint) — the page entry's `slot_tree_extents`, the affinity cap's input, `slot_tree_bytes_*`.
- `slot_state` record v2: `Unleased { root, cursor, g, slot_tree_extents, last_written, tails }` (fixed 44 B + tails), `Leased { appender_id, g, page_addr, root, cursor, slot_tree_extents }` (46 B); `SlotState::recorded_root()`; the forest open and the reader resync resolve a `Leased` root through the lessee's page (`leased_root_from_directory`, newest seq wins) and SKIP the native slot's record (it is the plane's).
- `AppenderRegion.leases: ArcSwap<BTreeSet<ForestSlot>>` (dynamic — `add_lease` / `drop_lease`); `AppenderRegion.released`; `AppenderSet.leases: Option<Arc<SlotLeasePlane>>`; `lease_page_entries` writes every page's entries with the live `g`, extents, root and cursor.
- `RegionGrant::transfer_out / transfer_in`: a slot tree's live image extents (`KvTree::reachable_node_addrs` → extents) leave the departing appender's grant record with the release and join the requester's with the grant — the closure law reads them as returned / granted (§6 item 4).

### 1.5 The crash rows and C14 (`settle_page_entries_against_tree0`)

The open snapshots every in-process region's `Live` page's slot entries into the plane BEFORE the join's checkpoint rewrites the pages from the (empty) RAM lease set (§6 item 3); the arm settles them: two `Live` attestations of one slot across the loaded pages and the directory's foreign `Live` pages, or a `Live` entry contradicting tree 0's lessee at a higher `g`, REFUSE the mount loud naming both appenders and the class (`slot_lease_conflicts`; the remedy is PR 10's `appender clear`); a `Releasing` entry on our page with tree 0 still leasing the slot to us at that `g` is COMPLETED from the page's words (row 5 — tree 0 `Unleased { root, cursor, g }` from the page, tails from the flushed tree); one tree 0 no longer leases to us is DROPPED (row 6 — tree 0 wins). Row 7 (the manager dies after the release, before the requester's page named the slot) is the requester's idempotent retry against the successor; row 8 (the requester dies after its page named the slot) leaves the lease with the page — its re-join answers `already` at the same `g`.

### 1.6 The membership carriage and the venue

- `membership::Grant` gained `slot_leases_ack: SlotLeasesAck { prior_epoch, slots: [(routing slot, g)] }`, `slot_release_notices: Vec<u16>`, `offered_slots: Vec<(u16, g)>` (positional bincode under `CLUSTER_WIRE_SCHEMA` 5 — the program's unreleased wire; every construction site extended). The owner fills them at the join and every renewal through an installed source (`install_slot_lease_carriage_source`, the `lane_supply_for_member` precedent): every armed plane registers (`slot_lease::register_carriage_plane`), the source parses the member id (`cowriter::parse_node_member_id` — `node_{token:016x}[.m{slot:08x}]`) to `(node_token, mount_slot)` and each plane answers the appender ids whose page identity matches (`SlotLeasePlane::identities`, learned from the directory at the arm and at every wire join) — O(held slots) off the RAM table, never a scan. A wire holder's accepted offer records a RECALL (`SlotLeasePlane::note_recall`, `slot_recall_notices`) carried as `slot_release_notices`, cleared by its `ReleaseSlot`.
- `ManagerSetService` (`meta_ship/manager.rs`) dispatches the frame's volume ordinal to the volume's `ManagerService`; `AsyncVerbRouter::with_manager` claims the `0x0500` block; `arm_multi_writer` adds it when any volume of the set armed the plane; `ManagerClient::for_volume` addresses it. A symmetric mount without the multi-writer arm stands up no listener (it has no wire appender to serve — N daemons on one volume is PR 12's join ladder).

## 2. The negative contract — `SQUEEZEFS_SYMMETRIC_META=0` and a bit-17-absent volume are untouched

`symmetric_meta_off_is_the_shipped_dark_forest`: no plane (`slot_leases()` `None`, `slot_lease_stats()` `None`), `dlm_mode` = `solo`, tree 0 holds only the checkpoint's `Unleased { g: 0 }` roots, page 0's entries carry `g = 0`, the Slot-lease family absent. `symmetric_meta_on_a_flat_volume_refuses_naming_enable_symmetric`: `=1` on a bit-17-absent volume refuses the open naming `enable-symmetric` and `bit 17`, the flat volume untouched. The flat leg of the 26-suite matrix runs every pre-forest KV suite unchanged (§4). The hot-path hooks (`ensure_leases_for_tx`, `note_slot_ops`, the mint policy, the gate) are inert until `gate.arm()` — `slot_leases()` filters on the armed flag, so an unarmed forest pays one relaxed load per commit and a flat volume nothing (no `appenders` set).

## 5. Where the contracts needed PR 5+ machinery — stopped and stated

- **A wire holder's flush-then-transfer** needs the holder's own mount to run it (its node cache, its ring, its page): in PR 4 the recall reaches a wire holder as `slot_release_notices` on its renewal grant and the requester retries — the holder-side act on that notice is PR 12's (every mount a writer). The in-process contracts exercise the holder side through the manager's own regions.
- **The metanode ship for a foreign slot's mutation** (the commit door's "ship to the holder" refusal is EAGAIN-class and names the holder) is PR 6/12's; PR 4 refuses, never ships.
- **A dead appender's `Live` page** is left to PR 10's death ledger (the settle drops its `Releasing` entries and reads its `Live` entries as attestations; a same-node `Live` page is own residue).
- **Tokens over foreign metadata** (PR 5): a non-writer's view stays PR 1's partial-by-slot projection.
