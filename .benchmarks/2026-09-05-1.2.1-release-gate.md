## What this gate does and does not say

* The shipped code passes the full cargo gate and all three external POSIX
  suites from zero, with no failure outside the four documented by-design
  shapes, and the zero-copy surface is executed to the last test on two
  kernels of the sqz series.
* The external suites ran on the **dev/gate profile** (`release`, thin
  LTO); the tagged artifacts are built by `task dist:*` (`dist`, fat LTO)
  from the tag in a pinned worktree — and since 1.2.0's `84d34424` the
  artifact check refuses a binary whose version line does not end in the
  profile it was built with.
* Loop devices / file-backed sandboxes on one box — a conformance venue,
  never a performance row. The 1.2.1 performance claim (D-1c, +6 %
  full-save ingest on the field box, par elsewhere) has its own two-venue
  record, `.benchmarks/2026-09-04-d1c-conveyor-group-per-frame.md`.
