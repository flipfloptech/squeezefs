## Red-first bugs found in the suite (rung 4)
- A fresh `sync.channel.Mpsc` with no sender yet read as closed/drained: receiver scheduled first exited, producer parked forever → ~1-in-4 full-suite hang. Fixed with a `connected` word.
- Lost 4 KiB overwrite: a write read its base from the durable map while an unsaved rewrite-epoch shadow existed and the closing epoch left its table before the save landed. Fixed via `Epochs.baseBinding`, `Epochs.closing` visibility, serialized closes per ino.
- Lesson: when the full unit suite hangs but every subset passes, suspect an intra-test scheduling race (Io.Threaded run queue is LIFO), not cross-test interaction.
- The 5 s 'stall' was a watchdog phantom (age = now − coarse tick stamp); ticked-reregister counters now count rescues only.
- data/transform's key-file test calls `hardenProcess()` (PR_SET_DUMPABLE=0) in-process, which blinds `/proc/<pid>/{stack,syscall,fd}` for all later tests.
